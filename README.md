✅ Loan Application Process Optimization – Business Analyst Project

A complete Business Analyst case study in the BFSI domain, covering BRD, AS-IS/TO-BE workflows, User Stories, UAT Test Cases, and Gap Analysis.
This project demonstrates end-to-end BA documentation, process understanding, and workflow optimization for a loan application lifecycle.

📌 Project Overview

A mid-size financial institution is experiencing:

Long loan approval times (48–72 hours)

Manual document verification

Manual risk scoring

Inefficient handoffs between teams

No real-time tracking dashboard

This project proposes an optimized loan-processing workflow powered by automation, structured documentation, and clear business requirements.

🎯 Objectives

✔ Reduce loan approval time to under 24 hours
✔ Introduce automated KYC & risk scoring
✔ Improve communication between Credit, Risk & Support teams
✔ Build AS-IS & TO-BE workflows
✔ Define functional & non-functional requirements
✔ Prepare UAT test scenarios
✔ Conduct gap analysis to highlight improvement areas

📁 Project Deliverables (Included in Repository)
